# 🌐 Yvira Documentation Website (Pronto para GitHub Pages)

Site estático completo de documentação oficial e tutoriais da linguagem Yvira, desenhado para publicação no **GitHub Pages** ou qualquer CDN (Vercel, Netlify, Cloudflare Pages).

---

## 🚀 Como testar localmente
Basta abrir o arquivo [`index.html`](file:///C:/Users/santh/OneDrive/Área de Trabalho/ARQQUIVOS DRIVE/Beta OS/yvira_docs_site/index.html) em qualquer navegador web (Edge, Chrome, Firefox).

---

## 📦 Como Publicar no GitHub Pages
1. Crie um repositório no GitHub (ou use a branch `gh-pages` / pasta `/docs` do seu repo atual).
2. Copie o conteúdo desta pasta (`index.html` e `yvira-logo.svg`).
3. No GitHub: Vá em **Settings** -> **Pages** -> Selecione a branch e a pasta raiz (`/`).
4. Seu site estará online com domínio personalizado ou `https://seu-usuario.github.io/yvira-docs`!

---

## 🎨 Recursos do Site
- **Design Moderno:** Inspirado na documentação de ponta (Next.js / Vite / Tailwind).
- **Tema Dark Cyber:** Cores alinhadas com a identidade visual da linguagem e com o logo oficial SVG.
- **Botão de Copiar Código:** 1 clique para copiar qualquer snippet direto para o clipboard.
- **Filtro de Busca em Tempo Real:** Barra de pesquisa rápida na lateral para achar qualquer tópico em milissegundos.
- **Totalmente Standalone:** Sem dependências pesadas de frameworks, carrega instantaneamente.
