Linguagem Yvira — O Manual Definitivo

O Yvira é uma linguagem de programação moderna feita para resolver um problema real: você cria aplicações desktop lindas (com HTML e CSS), APIs velozes, chats em tempo real e cálculos matemáticos sem precisar instalar 50 ferramentas diferentes.

👶 Como se explica para uma criança?
Imagine que em outras linguagens, para fazer um carrinho andar, você precisa comprar as rodas na China (Node/npm), o motor nos EUA (Python) e o chassi na Alemanha (C#). No Yvira, o carrinho já vem montado na caixa pronto para pilotar!
🖥️ GUI Nativa (HTML/CSS)
💻 CLI Central com Menus
💾 SQLite Embutido
⚡ Async @spawn
🔒 Criptografia AES-256
📦 Gera .exe Independente

1. Usando o Yvira no Terminal (PowerShell / CMD)

Depois de instalado, o Yvira fica disponível direto no seu terminal em qualquer pasta do seu computador.

🤔 Por que isso existe? Para você não precisar abrir programas pesados só para rodar um script. Você abre o PowerShell ou CMD e o Yvira te responde na hora.

A. O Menu Interativo Central

Se você abrir o terminal e digitar apenas yvira (sem nada depois), ele abre uma central de comandos visual onde você usa as setinhas do teclado para escolher o que fazer:

PowerShell
yvira

B. Rodando um Arquivo de Código (.yv)

Para rodar qualquer código que você escreveu:

PowerShell
yvira run meu_codigo.yv
# Passando argumentos para o script:
yvira run meu_codigo.yv --porta 8080

C. Formatador Automático de Código (yvira fmt)

Deixa seu código limpo, alinhado e padronizado automaticamente (também funciona com Shift + Alt + F no VS Code):

PowerShell
# Formata um único arquivo:
yvira fmt meu_codigo.yv

# Formata todos os arquivos .yv do projeto recursivamente:
yvira fmt .

D. O Console Interativo (REPL)

Quer testar uma conta ou uma função rápida sem criar nenhum arquivo? Abra o REPL com destaque de cores:

PowerShell
yvira repl

2. Criando um Projeto Novo (yvira init)

Para começar um sistema organizado com toda a estrutura pronta de pastas, use o comando yvira init:

PowerShell
yvira init meu_sistema

Ele cria instantaneamente essa árvore de arquivos pronta para você:

Estrutura Gerada
meu_sistema/
├── yvira.json      # Manifesto do projeto (nome, versão, dependências)
├── main.yv         # Arquivo de entrada principal do código
├── .env            # Configurações de banco e segredos
└── views/          # Telas HTML/CSS da sua aplicação
    └── index.html  # Sua página visual pronta

3. Instalando Pacotes e Módulos (yvira install)

Precisa de uma biblioteca que um amigo ou a comunidade fez? Você pode instalar direto do GitHub ou de uma URL da internet:

PowerShell

# 2. Instala com apelido curto

4. Variáveis, Constantes e Textos Inteligentes ($)

Como guardar informações na memória do computador com a sintaxe do Yvira:

🤔 O que é uma variável? É como uma caixinha com uma etiqueta. Se a etiqueta diz let nome, você pode guardar um texto lá dentro. Se for const, você passa fita isolante e ninguém nunca mais pode trocar o que está lá dentro!
variaveis.yv
# let: pode mudar de valor no futuro
let jogador = "Santhyago";
let pontos = 150;
let estaVivo = true;

# const: valor fixo que o Yvira impede de mudar
const GRAVIDADE = 9.8;

# Interpolação ($): Coloque variáveis dentro do texto sem usar + + +
let mensagem = $"O jogador {jogador} tem {pontos} pontos agora!";
print(mensagem);

4.1. Todos os Operadores da Linguagem (Matemática, Comparação e Lógica)

No Yvira você pode fazer contas, comparar valores e criar regras lógicas complexas. A linguagem aceita tanto símbolos matemáticos clássicos quanto palavras em inglês (estilo Python/C#), o que você preferir!

👶 Como explicar para uma criança?
Operadores são como as ferramentas da sua caixa de brinquedos:
• Os aritméticos (+, -, *, /) são como sua calculadora da escola.
• O incremento (++) é como subir um degrau da escada de cada vez.
• Os comparadores (==, !=, >, <) são o juiz do jogo de futebol apitando se foi falta ou não.
• Os lógicos (and, or, not) são como as regras da sua mãe: "Você só vai passear se arrumar a cama E fizer a lição de casa!"

D. Operadores Lógicos (Juntar Várias Condições)

O Yvira aceita tanto os símbolos &&, ||, ! quanto as palavras em inglês and, or, not:

operadores_logicos.yv
let idade = 20;
let temCarteira = true;
let estaChovendo = false;

# 1. 'and' (ou '&&'): As duas coisas PRECISAM ser verdadeiras ao mesmo tempo
if (idade >= 18 and temCarteira) {
    print("Pode dirigir o carro!");
}

# 2. 'or' (ou '||'): BASTA UMA das coisas ser verdadeira
let temCartao = false;
let temDinheiro = true;
if (temCartao or temDinheiro) {
    print("Pode pagar a conta!");
}

# 3. 'not' (ou '!'): Inverte a lógica (O que é falso vira verdadeiro!)
if (not estaChovendo) {
    print("Tempo limpo! Pode ir para a praia sem guarda-chuva.");
}

6. Listas e Mapas (Dicionários)

Guardar muitos dados juntos sem bagunça:

🤔 Qual a diferença?
• Lista [ ... ]: É uma fila numerada (0, 1, 2...). Ótimo para rankings ou listas de compras.
• Mapa { ... }: É uma ficha de cadastro onde cada informação tem um nome (nome: "Carlos", idade: 25).
listas_mapas.yv
# 1. Lista
let frutas = ["Maçã", "Banana"];
frutas.push("Uva");          # Coloca no final
frutas.insert(0, "Morango"); # Coloca no começo (posição 0)
print($"Total de frutas: {len(frutas)}");

# 2. Mapa
let produto = {
    "id": 101,
    "nome": "Teclado Gamer",
    "preco": 250.0,
    "emEstoque": true
};
print($"Preço: R$ {produto.preco}");

7. Tomando Decisões no Código: If, Else, While, For-In e Match

👶 Como explicar para uma criança?
Imagine que você é o motorista de um carro e chega numa bifurcação na rua:
• O if ("SE") é a placa dizendo: "SE o sinal estiver verde, siga em frente."
• O else ("SENÃO") é o que você faz se a placa for falsa: "SENÃO, pare o carro imediatamente!"
• O while ("ENQUANTO") é como andar em círculos numa rotatória: "ENQUANTO o combustível não acabar, continue rodando."

A. Como o If e Else funcionam por dentro

O computador avalia uma pergunta que só pode ter duas respostas: Verdadeiro (true) ou Falso (false). Se for verdadeiro, ele entra nas chaves { ... } do if. Se for falso, ele pula direto para o else:

exemplo_if_else.yv
let saldoNoBanco = 150.0;
let precoDoJogo = 200.0;

# Pergunta: 150 é maior ou igual a 200? FALSO!
if (saldoNoBanco >= precoDoJogo) {
    print("Parabéns! Você comprou o jogo!");
    saldoNoBanco = saldoNoBanco - precoDoJogo;
} else {
    # Como a pergunta deu FALSO, o computador é obrigado a vir para cá:
    let quantoFalta = precoDoJogo - saldoNoBanco;
    print($"Você não tem dinheiro suficiente. Faltam R$ {quantoFalta}.");
}

B. O While (Repetidor com Condição)

O while repete um bloco de código de novo e de novo enquanto a condição for verdadeira. Tome cuidado para sempre aumentar o contador, senão ele roda para sempre (loop infinito):

exemplo_while.yv
let voltasNaPista = 1;

while (voltasNaPista <= 3) {
    print($"Completou a volta número: {voltasNaPista}");
    # Aumenta 1 na volta para ele saber quando parar!
    voltasNaPista = voltasNaPista + 1;
}
print("Fim da corrida! Bandeira quadriculada!");

C. O For-In (Percorrendo Listas sem contar números)

Se você tem uma lista de amigos, produtos ou servidores, o for-in pega um por um automaticamente do começo ao fim:

exemplo_for.yv
let amigos = ["Carlos", "Beatriz", "Lucas"];

for (nome in amigos) {
    print("Enviando convite para: " + nome);
}

D. O Match (O Selecionador Elegante)

Quando você tem uma variável que pode ter 5 ou 10 valores diferentes (ex: cargos, códigos de erro), ficar escrevendo if, else if, else if, else if é horrível. O match resolve isso numa tacada só:

exemplo_match.yv
let semaforo = "amarelo";

let acao = match semaforo {
    "verde"    => "Pode acelerar!",
    "amarelo"  => "Atenção! Comece a frear!",
    "vermelho" => "Pare totalmente!",
    _          => "Sinal quebrado! Ande com muito cuidado." # O _ é o padrão para qualquer outra coisa
};
print(acao);

8. Tratamento de Erros: Try, Catch, Finally e Throw (Para que serve cada um?)

👶 Como explicar para uma criança?
Imagine que você está brincando de malabarismo com pratos de louça caros:
• O try ("TENTE") é você dizendo: "Eu vou TENTAR equilibrar esses pratos aqui."
• O throw ("LANCE / JOGUE") é o alarme de emergência: "SOCORRO! O prato escorregou da minha mão e vai cair!"
• O catch ("PEGUE / CAPTURE") é a rede de segurança esticada no chão: Ela SEGURA o prato para não estraçalhar no chão e o programa não morrer!
• O finally ("FINALMENTE / SEMPRE"): É a sua mãe dizendo: "Dando certo o malabarismo ou quebrando tudo, no FINAL você vai ter que lavar as mãos e arrumar a sala!"

Por que isso é tão importante em sistemas reais?

Se você fizer um app de banco ou logística e a internet cair, o programa normal travaria e fecharia na cara do usuário. Com try/catch, você captura o erro, exibe uma mensagem bonita ("Por favor, verifique sua conexão") e a janela continua aberta e funcionando!

exemplo_erros_completo.yv
# Função que valida uma transferência bancária
fn transferirPix(saldoAtual, valorPix) {
    # 1. THROW: Nós mesmos criamos e disparamos um erro proposital
    if (valorPix <= 0) {
        throw "O valor do PIX deve ser maior que zero!";
    }

    if (valorPix > saldoAtual) {
        throw "Saldo insuficiente! Você não pode transferir o que não tem.";
    }

    return saldoAtual - valorPix;
}

# 2. TRY: Colocamos o código perigoso dentro do bloco de proteção
try {
    print("[1] Iniciando transferência PIX...");
    
    # Tentamos transferir R$ 800 tendo apenas R$ 200 de saldo (Vai disparar o throw!)
    let saldoRestante = transferirPix(200.0, 800.0);
    
    # Esta linha abaixo NEM VAI RODAR, porque o throw pula direto para o catch!
    print($"Sucesso! Novo saldo: R$ {saldoRestante}");

} catch (motivoDaFalha) {
    # 3. CATCH: O programa não morreu! Ele caiu suavemente aqui:
    print("[2] Operação cancelada com segurança pelo sistema:");
    print("    Motivo: " + motivoDaFalha);

} finally {
    # 4. FINALLY: Limpeza de recursos (fecha conexões, desliga câmera, etc.)
    # RODA SEMPRE, mesmo se deu erro ou se deu tudo certo!
    print("[3] Fechando sessão segura com o Banco Central.");
}

# Prova viva de que o app continua rodando:
print("[4] O sistema Yvira continua ligado normalmente!");

9. Orientação a Objetos (POO): O que é, Para que serve e Como usar?

👶 Como explicar para uma criança?
Imagine uma forma de fazer bolo no formato de coração:
• A classe (class) é a forma de metal. Ela não se come, ela é apenas o molde que define o tamanho e as características do bolo.
• O objeto (new) é o bolo de verdade saindo quentinho do forno. Você pode usar a mesma forma para fazer 10 bolos: um de chocolate com morango, outro de cenoura com brigadeiro!
• Os atributos (this.nome, this.saldo) são os ingredientes daquele bolo específico.
• Os métodos (funções dentro da classe) são as coisas que o bolo faz (ex: estragar, esfriar, ser fatiado).
• A herança (extends): Imagine que você inventou um bolo especial com recheio duplo. Em vez de criar uma forma do zero, você pega a forma antiga e só adiciona um detalhe novo!

Por que usamos Classes em vez de variáveis soltas?

Se você tiver 100 usuários no seu sistema, criar variáveis soltas como nome1, saldo1, nome2, saldo2, nome100, saldo100 deixaria seu código impossível de ler. Com classes, você agrupa as informações e os comportamentos em um único lugar organizado.

Análise Linha por Linha do Código de POO:

exemplo_poo_completo.yv
# 1. Definimos o MOLDE básico: ContaBancaria
class ContaBancaria {
    
    # constructor: É a função mágica que é chamada no exato segundo em que o objeto nasce!
    fn constructor(titular, saldoInicial) {
        # 'this' significa 'DESTA CONTA ESPECÍFICA'. Cada conta tem o seu titular e seu saldo:
        this.titular = titular;
        this.saldo = saldoInicial;
    }

    # Método de instância: Uma ação que a conta sabe fazer
    fn depositar(valor) {
        this.saldo = this.saldo + valor;
        print($"[+] R$ {valor} depositados na conta de {this.titular}.");
    }

    fn obterExtrato() {
        return $"Titular: {this.titular} | Saldo Disponível: R$ {this.saldo}";
    }
}

# 2. HERANÇA (extends): ContaVip herda tudo de ContaBancaria e ganha superpoderes
class ContaVip extends ContaBancaria {
    
    # Um método novo que só clientes VIP possuem:
    fn pedirEmprestimoSemJuros(valor) {
        this.saldo = this.saldo + valor;
        print($"[★ VIP] Empréstimo de R$ {valor} concedido com taxa ZERO para {this.titular}!");
    }
}

# ==========================================
# 3. COLOCANDO O MOLDE EM AÇÃO (INSTANCIAÇÃO)
# ==========================================

# Criamos o primeiro objeto (Conta do Carlos)
let contaCarlos = new ContaBancaria("Carlos Silva", 500.0);

# Criamos o segundo objeto independente (Conta VIP da Ana)
let contaAna = new ContaVip("Ana Prado", 50000.0);

# Usamos os métodos de cada uma:
contaCarlos.depositar(200.0); # O saldo do Carlos sobe para 700.0 (O da Ana continua intocado!)
contaAna.pedirEmprestimoSemJuros(10000.0); # Ana usa o poder VIP dela!

# Imprime o extrato de cada conta:
print(contaCarlos.obterExtrato());
print(contaAna.obterExtrato());

10. Criando Janelas Desktop com HTML e CSS (create_window)

Chega de criar telas feias com cara de Windows 95. No Yvira você cria a tela usando **HTML5 e CSS moderno** (com animações, modo escuro e fontes bonitas), e a linguagem abre a janela nativamente com aceleração por GPU (WebView2).

🤔 Como o Yvira faz isso? Ele abre um navegador ultrarrápido sem barras, sem abas e transparente. O usuário pensa que é um app comum do Windows, mas por trás é o seu HTML e CSS brilhando!
main.yv
let app = create_window({
    "title": "Meu Sistema Yvira",
    "view": "views/index.html",     # Seu arquivo HTML
    "width": 1100,
    "height": 720,
    "frameless": true,              # Tira a barra feia clássica do Windows
    "background": "#0b0f19"
});

# Mostra a tela e espera o usuário fechar
app.show();
app.wait();

12. A Ponte Yvira ↔ JavaScript (Sem JSON e Sem Enrolação)

A melhor parte do Yvira: você não precisa fazer JSON.parse nem requisições fetch!

🤔 Por que é tão fácil? Porque o Yvira e a janela estão morando na mesma casa (mesma memória RAM). O Yvira joga o dado na bandeja do JavaScript e ele já cai como objeto pronto!
1. Do Yvira para a Tela (Yvira manda, JS desenha):
• No Yvira: app.emit("atualizar_saldo", { valor: 500 });
• No JS: window.atualizar_saldo = function(dados) { alert(dados.valor); };
2. Da Tela para o Yvira (Usuário clica, Yvira processa):
• No JS: window.yvira.emit("salvar_cliente", { nome: "Alan" });
• No Yvira: app.on("salvar_cliente", fn(dados) { print(dados.nome); });

13. Tutorial: Fazendo a Tela Atualizar Sozinha ao Vivo

Veja como é simples mudar números e animar barras na tela conforme o Yvira envia dados:

views/index.html (JavaScript)
// Essa função roda toda vez que o Yvira manda dados novos
window.receber_dados_etl = function(pacote) {
    const m = pacote.metricas;
    
    // 1. Atualiza o texto do faturamento
    document.getElementById('valorVendas').innerText = "R$ " + m.vendasDia;

    // 2. Anima a barra de separação mudando a largura no CSS
    let porcentagem = (m.totalSeparado / m.meta) * 100;
    document.getElementById('barraFill').style.width = porcentagem + "%";
};

15. Criando APIs REST e Microserviços (http.serve)

Crie servidores web com rotas GET e POST em menos de 15 linhas:

servidor_api.yv
import "http" as http;

fn meuRoteador(req) {
    # Rota GET para listar produtos
    if (req.method == "GET" && req.path == "/produtos") {
        return { "sucesso": true, "itens": ["Monitor", "Teclado"] };
    }

    # Rota POST para cadastrar (req.body já é um Mapa!)
    if (req.method == "POST" && req.path == "/produtos") {
        let nome = req.body.nome;
        return { "status": 201, "mensagem": "Produto cadastrado: " + nome };
    }

    return { "status": 404, "erro": "Rota inexistente" };
}

# Coloca a API no ar ouvindo na porta 8080
http.serve(8080, meuRoteador);

16. Banco de Dados SQLite Embutido (@db, @exec & @query)

Salve dados para sempre no disco sem precisar instalar PostgreSQL, MySQL ou qualquer driver:

banco_dados.yv
# Conecta ao arquivo (ele cria o arquivo se não existir)
@db("sqlite://dados_armazem.db");

# 1. Cria tabelas e insere dados com @exec (usando ? para evitar invasões)
@exec("CREATE TABLE IF NOT EXISTS clientes (id INTEGER PRIMARY KEY, nome TEXT, saldo REAL);");
@exec("INSERT INTO clientes (nome, saldo) VALUES (?, ?);", ["Santhyago", 1500.0]);

# 2. Faz buscas com @query (Devolve uma Lista de Mapas!)
let lista = @query("SELECT id, nome, saldo FROM clientes;");
for (c in lista) {
    print($"Cliente: {c.nome} | Saldo: R$ {c.saldo}");

21. Super Matrizes e Álgebra Linear Científica

🤔 Por que o Yvira tem Matrizes nativas de 1ª Classe?

Em linguagens tradicionais como Python ou JavaScript, quando você quer multiplicar matrizes ou calcular a física de um jogo ou rede neural, você é obrigado a instalar bibliotecas externas gigantescas (como NumPy). No Yvira, o compilador e a VM já possuem um motor de álgebra linear científica integrado em C# nativo! Se você declarar qualquer array numérico simples [1, 2, 3] ou 2D [[1, 2], [3, 4]], ele vira instantaneamente um objeto YviraMatrix de altíssima performance.

D. Álgebra Linear Avançada: Multiplicação, Determinante, Inversa e Traço

Toda a precisão matemática exigida por engenharia, física e inteligência artificial:

algebra_linear.yv
let A = [
    [6, 1, 1],
    [4, -2, 5],
    [2, 8, 7]
];

# 1. Determinante exato por Eliminação Gaussiana
let detA = A.det(); # -306

# 2. Traço da Matriz (Soma dos elementos da diagonal principal)
let traco = A.trace(); # 6 + (-2) + 7 = 11

# 3. Transposição instantânea (inverte linhas por colunas)
let trans = A.transpose(); # ou A.T

# 4. Inversão de Gauss-Jordan com Pivoteamento Parcial
let quad = [
    [4, 7],
    [2, 6]
];
let inv = quad.inverse(); # ou quad.inv()

# Comprovação matemática: Matriz * Inversa = Matriz Identidade!
let identidade = quad * inv;
print(identidade); # [[1, 0], [0, 1]]

F. Resolução Automática de Sistemas Lineares (A · x = b)

O Yvira resolve sistemas de equações com a função solve(A, b):

sistema_linear.yv
# Vamos resolver o sistema de equações de Física/Engenharia:
#  2x +  y =   8
#   x - 3y = -10
# Solução matemática exata esperada: x = 2, y = 4

let A = [
    [2, 1],
    [1, -3]
];
let b = [8, -10];

# O Yvira calcula o vetor x através de x = A⁻¹ · b
let solucao = solve(A, b);

print("Vetor Solução [x, y]:", solucao); # [2, 4]

# Verificação de segurança: A * x DEVE ser igual a b!
let checagem = A * solucao;
print("Comprovação A * x:", checagem);  # [8, -10] comprovado!
