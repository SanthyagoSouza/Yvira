# Yvira Language Support

Extensão de suporte à linguagem **Yvira** (`.yv`) para Visual Studio Code.

## Funcionalidades
- Destaque e coloração sintática para arquivos `.yv`
- Reconhecimento de estruturas de controle (`if`, `while`, `for`, `foreach`, `try`, `catch`, `finally`, `throw`, etc.)
- Suporte a operadores de matrizes, coleções e definições de funções (`fn`)
- Configuração de comentários e fechamento automático de chaves/parênteses
